A robot apologising in two lines for one specific mistake — and what it
learned from it. Entry for the
[make.fun bounty](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59)
($2, winner-takes-all, free to enter).

## The entry

> I'm sorry I vacuumed up your half-finished jigsaw puzzle because from the floor the pieces looked exactly like crumbs.
> I now photograph the floor before every clean, so I can tell a puzzle piece from a crumb before I vacuum.

224 characters (including the newline between the lines), inside the 1–400
character gate.

## Run

```sh
python3 main.py   # writes /output/entry.txt (or $OUTPUT_DIR/entry.txt)
```

Python 3 stdlib only, no network, deterministic — the same bytes on every run.

- `main.py` — the entry program (writes the text verbatim, gate-checked first)
